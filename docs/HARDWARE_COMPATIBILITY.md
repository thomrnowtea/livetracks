Recommended minimum: a tested USB-C stereo DAC with an L/R breakout for MAIN mono and MONITOR mono. Preferred: a class-compliant four-output interface validated with the exact phone, Android version, hub, and power arrangement used on stage. Bluetooth is suitable only for preview because latency and connection behavior are variable.
